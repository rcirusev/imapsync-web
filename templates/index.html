Bulk migration from a CSV file

Each row is a fully independent migration (its own source/destination accounts and options) — handy for migrating many mailboxes onto a new server at once. Rows run one at a time, in file order, so the source/destination servers aren't hit with many connections simultaneously.

Download the CSV template to see the exact columns expected (required: host1, user1, password1, host2, user2, password2 — everything else is optional per row).

Stores every row's passwords, encrypted, so the batch can log back in on its own — the one case in this app where passwords aren't single-use. Manage or turn off any time from History → Scheduled delta syncs.

The file is parsed in memory and never saved to disk. Passwords are held only for as long as each row's own migration is running, exactly like a single migration.
